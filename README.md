# مدارس WE للتكنولوجيا التطبيقية - الشرقية | منصة الكادر التعليمي والإداري
## WE Sharkia Applied Technology School - Staff & Administration Dashboard

منظومة إدارية وتعليمية متكاملة لإدارة مدرسة WE للتكنولوجيا التطبيقية بالشرقية، تشمل إدارة الفصول، الجداول المدرسية، الحضور والانصراف، شؤون الطلاب، الموارد البشرية، الأخصائي الاجتماعي، والجودة.

---

### 🚀 المميزات الرئيسية (Core Features):
- **لوحة مدير المدرسة (Manager Hub):** متابعة مؤشرات الأداء، تقييم المعلمين، التكليفات المدرسية، وحضور الكوادر.
- **شؤون العاملين والموارد البشرية (HR & Staff Affairs):** تسجيل حضور الموظفين، طلبات الإجازات، التحقيقات الإدارية، والمذكرات الرسمية.
- **الجدول المدرسي العام (Master Schedule):** استعراض الحصص وجداول الفصول والمعلمين والملاعب والمعامل الذكية.
- **شؤون الطلاب (Student Affairs):** متابعة الفصول، بيانات الطلاب، وإدارة طلبات أولياء الأمور.
- **التربية الرياضية (Sports & Activities):** تقييمات اللياقة البدنية والأنشطة والبطولات المدرسية.
- **الامتحانات والتحسين (Exams & Assessment):** إدارة الامتحانات التكوينية وجلسات الدعم والتحسين.

---

### 💻 التقنيات المستخدمة (Tech Stack):
- **Frontend:** React 19 + Vite + Tailwind CSS
- **Icons & UI:** Lucide React
- **Backend API:** ASP.NET Core Clean Architecture
- **Database:** Microsoft SQL Server

---

### ⚙️ التشغيل محلياً (Run Locally):
```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev
```

---

### 🌐 النشر (Deployment):
مهيأ للنشر المباشر على **Vercel** بواسطة [`vercel.json`](./vercel.json) المدمج مع Reverse Proxy للاتصال الآمن بالباك إند.
